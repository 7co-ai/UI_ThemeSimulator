# UI Theme Designer Simulator

スマートフォンの実機検証（PWAフルスクリーン対応）およびPCブラウザの両環境に最適化された、2〜5色のUIカラーパレット設計・モックアップ検証シミュレーターです。

外部サーバーや事前ビルドは一切不要。単一のHTMLファイル（`index.html`）をブラウザで開くか、GitHub Pagesにデプロイするだけで即座に稼働します。

---

## 🌟 主な機能

1. **2〜5色 可変カラーパレット**
   - 2色・3色・4色・5色のスロット切替
   - カラーピッカーによる直感的な色選択 ＆ HEXカラーコード直接入力
   - 5色サンプルのリアルタイムプレビュー表示

2. **単色（フラット） / ドット・ストライプ・グラデーション塗りのワンタップ切替**
   - ヘッダー、ボタン、アクセントパーツの塗りを「グラデーション」と「単色」で瞬時に切り替え

3. **スマホ実機モックアップ（3画面カルーセル検証）**
   - **画面1（ダッシュボード）**: ヘッダーグラデーション、進捗バーチャート、数値指標、メインボタン
   - **画面2（タスク一覧）**: テーブル見出し、ステータスバッジ、リスト行の視認性確認
   - **画面3（設定・プロフィール）**: アバターバナー、トグルカード、フォームUIのバランス検証

4. **アクセシビリティ（白文字コントラスト比）自動判定**
   - WCAG基準に基づく背景明度計算により、ヘッダー上の白文字の視認性（良好 / 注意）をリアルタイム判定

5. **データ永続化（localStorage同期）**
   - 編集中のパレットや保存したマイパレットはブラウザ内に自動保管され、リロードや再訪時もそのまま復元

6. **豊富な書き出し・読み込み機能**
   - **CSS変数コピー**: `:root { --color-1: ...; }` をワンクリックでクリップボードへ保存
   - **HEX一覧コピー**: カンマ区切りのカラーコードリストを瞬時に取得
   - **JSONエクスポート / インポート**: 作成したカラーテーマをファイルとして保存・共有・復元

7. **PWA / モバイル最適化**
   - スマートフォン閲覧時は親指操作しやすい下部タブナビゲーション（カラー編集／実機プレビュー／テーマ一覧）を展開
   - iOS Safari / Android Chromeで「ホーム画面に追加」を行うことで、ブラウザのアドレスバーが隠れ、フルスクリーンのネイティブアプリ感覚で起動

---

## 🛠 技術スタック

- **UI & State**: HTML5 + Vanilla JS + [Alpine.js](https://alpinejs.dev/) (CDN)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) (CDN)
- **Icons**: [Lucide Icons](https://lucide.dev/) (CDN)
- **Storage**: Web Storage API (`localStorage`)
- **Hosting**: GitHub Pages 対応（完全クライアントサイド動作）

## 🚀 使い方

### 1. ローカル（PC）で直接使う場合
1. 本リポジトリの `index.html` をダウンロードします。
2. ダウンロードした `index.html` をブラウザ（Chrome、Safari、Edgeなど）にドラッグ＆ドロップして開くだけで使用できます。

### 2. GitHub Pages でスマホアプリとして使う場合
1. 本リポジトリの **Settings（設定） ＞ Pages（ページ）** を開きます。
2. **Build and deployment** の **Branch** を `main`、フォルダを `/(root)` に設定して **Save** を押します。
3. 発行されたURL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）をスマートフォンのブラウザで開きます。
4. 共有メニューから **「ホーム画面に追加」** をタップすると、ホーム画面からワンタップで起動する専用アプリとして利用できます。
